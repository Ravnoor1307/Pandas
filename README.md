# 🐼 Pandas

> A hands-on repository for learning **Pandas from fundamentals to practical data analysis**, covering Series, DataFrames, data manipulation, data cleaning, grouping, combining datasets, MultiIndex, string operations, DateTime analysis, and real-world projects.

---

## 📖 About

Pandas is one of the most important Python libraries for **Data Analysis and Data Science**.

This repository focuses on learning Pandas step-by-step, starting from the basic data structures and progressing toward real-world data analysis.

The main objective is to understand how to:

- Create and manipulate Series.
- Work with DataFrames.
- Select and filter data.
- Clean real-world datasets.
- Handle missing values.
- Detect and remove duplicate records.
- Group and aggregate data.
- Merge, join, and concatenate datasets.
- Work with MultiIndex Series and DataFrames.
- Perform vectorized string operations.
- Work with DateTime data.
- Perform exploratory data analysis.
- Build practical data analysis projects.
